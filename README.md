# CMF 排班助手

当前版本：**0.2.0**  
更新日期：**2026.08.24**

## 访问网址

- 在线应用：[https://cmf-scheduling-assistant.streamlit.app](https://cmf-scheduling-assistant.streamlit.app)
- GitHub 项目：[https://github.com/mangoruns-algae/cmf-scheduling-assistant](https://github.com/mangoruns-algae/cmf-scheduling-assistant)
- 本地运行地址：[http://127.0.0.1:8501](http://127.0.0.1:8501)

## 平台简介

- **Streamlit**：一个用 Python 快速构建数据应用网页的平台；本项目使用它展示登录、排班创建、班表预览、人员定位和文件下载界面，并通过 Streamlit Community Cloud 提供在线访问。
- **GitHub**：一个用于保存和管理代码版本的平台；本项目使用 GitHub 存放源代码，并在代码更新后触发 Streamlit Cloud 自动重新部署。

## 使用方法

### 1. 登录

打开在线应用，输入分配的账户和密码。用户名不区分大小写。

- `Qingyuan_Qin`、`admin`：可创建、发布和预览排班。
- `Nicole_Shi`、`Biao_Jiao`：仅可预览已发布排班、定位个人班次和导出 PDF。

### 2. 创建并发布排班

1. 使用具有创建权限的账户登录。
2. 选择“排班创建者”。
3. 上传基于 `staff_scheduling_template.xlsx` 填写的数据文件。
4. 检查人员资源、用工需求和排班规则。
5. 点击“生成排班”。
6. 检查排班结果后，点击“锁定并发布班表”。

仅生成但未锁定的班表不会显示给预览者。

### 3. 预览班次

1. 选择“排班预览者”；只读账户登录后会自动进入该页面。
2. 查看创建者锁定并发布的当前班表。
3. 在“人员定位”中选择姓名：
   - 黄色整行表示该人员参与该项工作；
   - 蓝色日期表示该人员担任现场负责人；
   - 同一天未参与的其他工序不会高亮。
4. 点击“导出单页排班 PDF”保存查阅版本。

### 4. 本地运行

可双击 `start_app.cmd`，或者在项目目录执行：

```bash
pip install -r requirements.txt
streamlit run app.py
```

然后访问 [http://127.0.0.1:8501](http://127.0.0.1:8501)。

## 当前注意事项

- Streamlit Cloud 免费实例可能因长时间无人访问而休眠，首次打开需要等待唤醒。
- 当前发布状态保存在正在运行的 Streamlit 实例中；实例重启、休眠恢复或重新部署后，创建者可能需要重新锁定并发布班表。
- 如需长期保存历史班表，后续应接入数据库或云端文件存储。

## 版本规则

- 系统正式上线前，第一位和第二位版本号固定为 `0.2`。
- 后续每次功能或界面更新只增加第三位：`0.2.1`、`0.2.2`……`0.2.9`、`0.2.10`。
- 除非项目负责人明确通知，第一位和第二位均不修改。
- 每次修改必须同步更新网页页脚、README 和 `CHANGELOG.md` 中的版本号及日期。
