# AI驱动的智慧排班 MVP

第一版目标：尽快验证人员排班业务规则，而不是一次做成正式系统。

## 当前已实现
- Excel 上传
- 人员资格筛选
- 人员可用性过滤
- 本产线优先
- 跨产线借调
- 夜班资格检查
- 简单公平性：优先累计班次较少人员
- 缺员提示
- 人员 × 日期班表视图
- 排班结果 Excel 导出

## 运行方式

```bash
pip install -r requirements.txt
streamlit run app.py
```

然后浏览器访问 `http://localhost:8501`

## 下一步建议
用真实的小范围人员和未来1周用工需求替换示例数据，先验证：
1. 哪些岗位/技能必须硬匹配；
2. 哪些产线之间允许借调；
3. 借调优先级；
4. 夜班与连续工作限制；
5. “培训/请假/固定岗位”等不可用条件。

连续工作天数、7天夜班数、总工时等规则目前尚未做成硬约束，建议在真实数据验证后再加。
